## Snapline 0.1.12 — Built-in image editing and annotation

- 截图卡片右键 **编辑 / 标注…**，或预览页点 **编辑 / 标注**；组内单张也可用。
- 画笔、高亮、箭头、矩形/圆框、文字、裁剪、马赛克和不透明遮挡。
- 颜色/线宽、缩放/适应窗口、撤销/重做（100 步）；Esc 取消当前手势。
- **完成并挂回** 保存新 PNG 到栏；另存 PNG 使用新文件名，原图/已有文件不覆盖。
- 复制的是当前编辑/裁剪结果；复制不等于保存，未保存关闭会确认。
- 导出扁平 PNG，不含本次编辑图层或原图载荷；组内原成员保持不变，编辑副本独立添加。
- 马赛克不保证信息不可推断；敏感区域请用不透明遮挡，分享编辑后的副本而非仍保留的原图。

开发验证记录：114 核心检查、140 隔离 UI/像素/已有功能回归检查通过，原图字节保存前后不变。
实际发布包测试以 pipeline manifest/报告为准；物理鼠标绘制、原生另存/关闭确认、透明图、超大图及各类字体/DPI仍需人工验收。
首版不支持旋转、JPEG 压缩、标注选择/移动和图层工程保存。
